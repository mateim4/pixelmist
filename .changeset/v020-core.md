v0.2.0: Add AccentScope per-product accent theming API to core, react, and native packages. This allows overriding semantic accent colors for specific UI sections.

- **@pixelmist/core**: Add `AccentScope`, `useAccentScope`, `useAccentColor` utilities
- **@pixelmist/react**: Add `AccentScope` component that sets CSS custom properties
- **@pixelmist/native**: Add `AccentScope` component for React Native
